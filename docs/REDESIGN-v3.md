### Phase 2 체크리스트 (v2 에서 실제로 걸렸던 함정)

- `#search-input` 은 "검색 중인가" 판단의 원본(16곳) → **지우지 말고 숨긴다**.
- 요소를 지울 때 **선택자 전역 검색** 필수 (`canStartPull`, `onNavTouchStart` 가 id 를 참조).
- 헤더 높이가 바뀌면 `updateStickTop()` 확인.
- **id 선택자는 `lg:hidden` 을 이긴다** → 보이기/숨기기는 `@media` 한 곳에서.
- 색·투명도 잴 때 `* { transition:none; animation:none }` 끼우고 잰다.
- ← → 키는 입력칸에 커서가 있으면 무시.

### Phase 11 계획 (2026-10-10)

**상황** : v3.0 은 이미 `main` 에 머지·출시됐다(이후 개인화 작업까지 `main` 에 들어감). 옛 `v3` 브랜치는 Phase 10 에서 멈춰 있으므로 쓰지 않는다.

### Phase 9 에서 배운 것

- 모바일 골격 CSS 를 데스크톱 블록 바로 뒤에 두었더니, 그보다 **뒤에 있는 공용 규칙(`.cat-chip` · `.view-toggle button`)에 졌다.** 같은 특이도면 나중 규칙이 이긴다 → `#cat-chips .cat-chip` · `#view-toggle button` 처럼 id 를 붙였다.
  카드/목록 모바일 규칙은 아예 데스크톱 `.bc-*` · `#news-list .bc-row` 규칙 **뒤에** 따로 두었다.
- 예전 모바일 블록(`@media (max-width:1023px)`, 파일 뒤쪽)에 남은 `#cat-header h2` · `#live-badge` · `#status-bar` 규칙이 새 규칙을 덮었다 → 새 블록으로 옮기고 지웠다.
- `main` 좌우 여백은 `px-4` = **1rem = 15px**(루트 15px)이라 16px 로 빼면 1px 씩 넘친다. 화면 끝까지 닿게 할 때는 `-1rem` 을 쓴다.
- 미리보기 창은 폭을 바꿔도 **화면을 한 번 그리기 전에는 resize · matchMedia 이벤트가 오지 않는다.** 1023 ↔ 1024 시험은 크기를 바꾼 뒤 스크린샷을 한 번 찍고 잰다(Phase 2 의 ResizeObserver 와 같은 이유).
- **사파리는 버튼을 눌러도 포커스를 주지 않는다.** 그래서 `:focus-within` 으로 펼친 줄 안의 버튼은, 누르는 순간 입력칸 포커스가 빠져 줄이 사라지고 눌림이 허공에 떨어진다 → 그런 버튼은 그 줄에 두지 않는다(미리보기 브라우저는 크로미움이라 재현 안 됨).
- 이 PC 에서 다른 창(세션)이 같은 파일을 고쳐 커밋했다(`38b6304` 헤더 로고). 작업 전에 `git log` 로 최신을 확인하고, 문자열 치환 스크립트는 **치환 대상이 정확히 한 번 나오는지** 세고 고쳤다.
- 큰 묶음 치환은 bash 한 줄 `node -e '...'` 안에 작은따옴표가 섞이면 깨진다 → 스크래치 폴더에 .js 파일로 써서 돌렸다.
