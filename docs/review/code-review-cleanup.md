### 2-2. '안 쓰는 코드' 판정 기준

LSP/AST 참조 검색은 **쓰지 않는다**. 이 프로젝트는 `onclick="..."` · 템플릿 문자열 속 HTML · 실행 중에 만드는 주소(`/api/${base}/…`, `registerSubSectionRoute`)가 많아 도구가 놓친다.
→ **글자 그대로 찾기**로 `server.js` · html · `privacy.html` · `docs/` 전체에서 **선언 말고 0건**일 때만 '죽은 코드'로 본다.

```bash
grep -n -w "함수이름" server.js news-insight-naver.html privacy.html docs/*.md
```
